# [JSPen Studio] 포토샵형 네이티브 데스크톱 인터랙티브 스튜디오

> **하이브리드 데스크톱 아키텍처 (Python + PyQt6 QtWebEngine)**  
> 프레임리스 창, 커스텀 타이틀 바, 네이티브 파일 대화상자와 파일 연결은 Qt가 담당하고,
> 편집 화면은 내장 Chromium(QtWebEngine)에서 실행되는 HTML5 Canvas 2D 엔진입니다.
> 스튜디오 캔버스와 내보낸 JavaScript는 **같은 렌더링·모듈 엔진 코드**를 사용하므로 결과가 일치합니다
> (모든 템플릿에 대해 스튜디오 화면과 내보낸 결과를 픽셀 단위로 비교하는 자동 테스트가 있습니다).

## 1. 빠른 시작 (원클릭 실행)

폴더 안의 **`start.vbs`** (또는 **`JSPenStudio.pyw`**) 를 더블 클릭하면 콘솔 창 없이 바로 실행됩니다.
`start.bat`도 동작하지만 배치 파일 특성상 콘솔 창이 잠깐 보입니다.

* 의존성 설치 (최초 1회):
  ```bash
  pip install -r requirements.txt
  ```

* 터미널 직접 실행:
  ```bash
  python main.py
  ```

* 브라우저 모드 (Node.js 개발 서버, `http://localhost:3000`):
  ```bash
  npm start
  ```
  보안을 위해 기본적으로 `127.0.0.1`에만 바인딩됩니다 (`HOST`, `PORT` 환경 변수로 변경 가능).
  브라우저 모드에서 `Ctrl+S`는 `.jspen` 파일 다운로드, `Ctrl+O`는 파일 선택 창으로 동작합니다.

* 단독 실행 파일(.exe) 생성:
  `build_exe.bat`(또는 `python build_exe.py`)을 실행하면 파이썬이 없는 PC에서도 실행되는
  `dist\JSPenStudio\JSPenStudio.exe`가 만들어지고, 빌드 직후 자동으로 실행 점검(`--selftest`)을 합니다.
  옵션: `--onefile`(단일 exe, 시작이 느림), `--no-prune`(Qt 파일 정리 생략). GitHub Actions의 Windows 빌드 결과물도 받을 수 있습니다.

* 최신 수정 사항 받기 (매번 zip을 받지 않아도 됨):
  ```bash
  git clone -b claude/jspen-project-review-o8bisr https://github.com/TM-TOMATO/jspen.git   # 처음 한 번
  git pull                                                                                # 이후에는 폴더 안에서 이것만
  ```
  GitHub Desktop을 쓰면 `Fetch origin` → `Pull origin` 버튼으로 같은 일을 할 수 있습니다.

## 2. 주요 아키텍처 및 신규 기능

1. **프레임리스 윈도우 & 커스텀 타이틀 바 통합**:
   * OS 기본 투박한 타이틀 바를 제거하고, 앱의 메뉴바 줄을 직접 창 이동 드래그 및 최소화(`─`), 최대화(`□`), 닫기(`✕`)가 가능한 네이티브 타이틀 바로 통합.
2. **모듈 노드 모드 (Module Node Graph - Shift+Tab)**:
   * 상단 좌측 버튼 또는 `Shift+Tab`으로 전체 화면 비주얼 노드 편집기로 전환.
   * 스프라이트 노드, 모듈 노드, 모듈 합치기(Combine) 노드, 계산/설정(Math) 노드를 베지어 와이어로 연결.
   * **출력 노드(OUTPUT)에 연결된 모듈만 실제 런타임 및 내보내기에서 동작**합니다.
3. **포토샵형 레이어 & 스프라이트 계층 구조**:
   * 레이어(Layer)는 폴더/컨테이너 역할을 하며, 내부의 여러 스프라이트(도형, 곡선, 브러시, 텍스트)를 그룹 관리.
   * 레이어 접기/펼치기 및 드래그 앤 드롭으로 레이어 순서, 스프라이트 이동, 모듈 실행 순서 재배치 가능.
4. **타임라인 전체 드래그 기능 정상화 & 키프레임 다이아몬드 드래그**:
   * 렌더링 시 이벤트 리스너가 유실되지 않도록 완벽 보정.
   * 눈금자/그리드 스크러빙, 스플리터 높이 조절, 재생 헤드 드래그, 그리고 **캔버스 그리드 위의 키프레임 다이아몬드를 직접 마우스로 좌우 드래그하여 프레임 위치 이동** 가능.
5. **타임라인 키프레임의 모듈화 (Timeline Keyframe Module)**:
   * 타임라인에 찍은 키프레임이 모듈 단위(`timeline_keyframes`)로 캡슐화되어 노드 그래프에서 연결 및 제어 가능.
6. **실시간 모듈 미리보기 버튼 타임라인 이동 & `Ctrl+Space` 단축키**:
   * 미리보기 버튼이 타임라인 제어부로 이동하여 재생 컨트롤과 함께 관리되며, `Ctrl+Space`로 작업 도중 즉시 토글 가능.
7. **베지어 곡선 도구 (Bezier Curve Tool, C)**:
   * 3차 베지어 핸들(`cp1, cp2`)을 마우스로 실시간 조작하여 유려한 곡선 벡터 스프라이트 생성.
8. **브러시 도구 곡선 보정기 (Curve Stabilizer)**:
   * 옵션 바에서 `[곡선 보정 ON/OFF]` 토글 지원. 손떨림 없는 부드러운 스트로크 렌더링.
9. **창 팝업/플로팅 분리 기능 (Floating Panels, ⧉)**:
   * 속성 패널, 레이어 패널, 타임라인 헤더의 `⧉` 버튼을 누르면 패널이 화면 위에 독립적으로 띄워져 드래그 이동 및 크기 조절 가능.
10. **모듈 속성 인스펙터 & 작동 조건 설정**:
    * 레이어 목록이나 노드에서 모듈을 클릭하면 인스펙터에 모듈 세부 속성이 표시됨.
    * 사용자가 모든 파라미터를 수동 관리하며, 작동 조건(`상시`, `클릭 시`, `호버 시`, `키 입력 시`, `프레임 구간`)을 지정 가능.
11. **오픈소스 플러그인 시스템 & 환경 설정 (`Ctrl+,`)**:
    * 파일 메뉴 ➔ `환경 설정... (Ctrl+,)`에서 단축키 안내 및 오픈소스 플러그인 관리.
    * `window.JSPen.registerPlugin` API를 통해 누구나 자바스크립트 5줄로 커스텀 모듈 및 도구 추가 가능.
12. **스포이드 실시간 루페 스와치**:
    * 스포이드 도구(`I`) 사용 시 마우스 커서 옆에 실시간 색상 원형 돋보기와 16진수 색상 코드가 표시됨.
13. **플랫 2D 투명 체커보드 & 테두리 개선**:
    * 투명 배경의 입체감/그라데이션/그림자 셰이딩을 완전 제거하여 깔끔한 플랫 2D 격자로 변경.
    * 색상 선택 버튼의 흰색 테두리 제거 및 입력창 클릭 시 주황색 테두리 제거.
14. **돋보기 도구 조작 개선**:
    * 좌클릭: 확대, 우클릭: 축소, `Alt+클릭`: 100% 배율 초기화 및 아트보드 중앙 정렬.
15. **베벨(Chamfer)과 코너 라운딩(Radius)의 상호작용**:
    * 모따기된 베벨 모서리에 부드러운 곡률이 함께 조화되어 렌더링되며 수치가 상호 연동됨.

## 3. 포토샵 표준 1열 도구 모음 (Toolbox)

* ↖ `V` : **이동 도구 (Move Tool)** - 스프라이트 선택 및 8방향 자유 변형 박스
* ☩ `A` : **직접 선택 도구 (Direct Selection)** - 펜/곡선 앵커 포인트 및 핸들 개별 조작
* ⤹ `C` : **베지어 곡선 도구 (Bezier Curve Tool)** - 인터랙티브 핸들 벡터 곡선 드로잉
* ✒ `P` : **펜 도구 (Pen Tool)** - 다각 및 3차 베지어 벡터 드로잉
* ✎ `B` : **브러시 도구 (Brush Tool)** - 실시간 곡선 보정 기능 탑재
* ▭ `U` : **도형 도구 (Shape Tools)** - 사각형, 베벨 사각형, 타원/원
* T `T` : **문자 도구 (Type Tool)** - 텍스트 레이어 생성 및 타이포그래피 설정
* ⌖ `I` : **스포이드 도구 (Eyedropper)** - 실시간 커서 루페 색상 추출
* PAN `Space` : **손 도구 (Hand Tool)** - 뷰포트 자유 이동 (Pan)
* ⌕ `Z` : **돋보기 도구 (Zoom Tool)** - 클릭 확대, 우클릭 축소, Alt클릭 100% 초기화
* ◲ `D` / ⇄ `X` : 전경색/배경색 리셋 및 스왑

## 5. 실시간 모듈 미리보기와 내보내기

* **발동 조건 (언제 작동하나요?)**: 모듈을 선택하면 속성창에서 조건과 작동 방식을 고릅니다. 아래 파란 상자에 "클릭하면 작동을 시작해 계속 유지합니다"처럼 실제 동작이 문장으로 표시되고, 레이어 창의 모듈 줄에도 `클릭→계속` 같은 표시가 붙습니다.
  * 조건: 항상 / 마우스를 올렸을 때 / 클릭했을 때 / 키를 눌렀을 때(칸을 클릭하고 키를 누르면 등록) / 신호를 받았을 때(아는 신호 이름 목록 제공) / 화면 트리거가 가리킬 때 / 토글이 켜져 있을 때 / 타임라인 구간 안에서
  * 작동 방식: `조건이 맞는 동안만`, `한 번 발동하면 계속`, `발동할 때마다 켜기/끄기`, `발동 후 정해진 시간 동안`.
    `자동`은 클릭·신호로 움직임 모듈을 시작하면 계속 작동하고, 효과음·신호·링크 같은 한 번짜리 동작은 그 순간에 한 번 실행합니다.
  * 미리보기 중에는 캔버스 왼쪽 아래 **모듈 상태** 창에 모듈별 `● 작동 중 / ○ 대기`, 최근 신호, 마우스가 올라간 스프라이트, 누른 키가 표시됩니다 (클릭을 막지 않으며 ▾로 접을 수 있음).
* `Ctrl + Space`를 누르면 캔버스에서 모듈 엔진이 실행되어 드래그, 호버, 클릭, 추적, 토글, 카운터, 트리거, 파티클 등의 인터랙션을 바로 확인할 수 있습니다.
  미리보기 중에는 편집이 잠기며, 종료하면 문서가 미리보기 이전 상태로 복원됩니다. 노드 그래프에서 OUTPUT에 연결되지 않은 모듈은 실행되지 않습니다.
* **모듈 스택**: 한 스프라이트의 모듈은 위에서 아래 순서로 실행됩니다.
  * 타이밍 모듈(`듀레이션 및 지연`, `시차 도미노`)은 아래 모듈들을 정해진 시간에만 실행합니다.
  * 설정 모듈(`반복 루프 모드`, `이징 커브 프리셋`)은 아래의 트윈·시퀀서·지연 모듈 동작 방식을 정합니다.
  * 값 모듈(`마우스 위치`, `스크롤 휠`, `타이머`, `시퀀서`, `계산 노드` 등)이 만든 수치는 아래 `값 매핑기`의 `이전 모듈 값` 입력으로 받아 회전·크기·필터 등에 연결할 수 있습니다.
  * 예: `스크롤 휠` → `값 매핑기(이전 모듈 값 → 크기)` = 휠로 확대/축소되는 카드
* **두 가지 내보내기**
  * `Ctrl + E` **순수 JavaScript (Canvas)**: 스튜디오와 동일한 렌더링·모듈 엔진으로 텍스트, 이미지, 필터, 키프레임, 마우스·터치·키보드 인터랙션을 그대로 재생합니다.
    모듈을 쓰지 않는 문서는 엔진을 빼고 내보내 크기가 작아지며, 캔버스 안에 텍스트·링크 대체 콘텐츠를 넣어 화면 낭독기와 검색엔진이 읽을 수 있습니다.
  * **웹사이트 (HTML/CSS)**: 스프라이트마다 실제 HTML 요소로 내보내므로 텍스트 선택·검색 노출·링크가 그대로 동작합니다.
    모듈이나 키프레임이 있으면 같은 모듈 엔진이 HTML 요소의 위치·크기·투명도·색·텍스트·필터를 움직입니다.

## 6. 콘텐츠 만들기

* **이미지**: 파일 > 이미지 가져오기(`Ctrl+Shift+I`), 캔버스로 끌어다 놓기, 클립보드 붙여넣기(`Ctrl+V`).
  큰 이미지는 2048px로 줄여 문서에 넣습니다. 속성창에서 교체·맞춤 방식(채우기/전체 보이기/늘리기)·대체 텍스트를 설정합니다.
* **글꼴**: 텍스트와 텍스트 라벨에서 글꼴을 고르고, `+` 또는 파일 > 글꼴 파일 추가로 `.ttf/.otf/.woff/.woff2`를 문서에 넣을 수 있습니다
  (내보낸 결과물에도 포함).
* **폼**: 웹 > 폼 요소 삽입. 입력칸(텍스트·이메일·전화·숫자·여러 줄·체크박스·선택 목록)과 전송 버튼, 문의 폼 세트.
  미리보기와 내보낸 결과물에서 실제 입력칸으로 동작하고, 전송 버튼은 같은 레이어의 입력칸을 검증해 메일(mailto)·서버(POST)·신호로 보냅니다.
  입력값은 전역 변수 `form.이름`으로도 읽을 수 있습니다.
* **반응형 화면**: 메뉴바 오른쪽의 `데스크톱 / 태블릿 / 모바일`. 화면마다 위치·크기·글자 크기·표시 여부를 따로 지정합니다.
  새 화면은 데스크톱 배치를 그 폭으로 재배치한 상태로 시작하니, 필요한 부분만 다듬으세요.
  내보낸 웹사이트와 JS는 창 폭(태블릿 ≤ 1024px, 모바일 ≤ 600px)에 맞는 배치를 고른 뒤, 실제 창 폭에 맞춰 재배치합니다.
* **모듈 설정**: 블렌더 속성 패널처럼 숫자 칸을 좌우로 끌어서 조절합니다 (Shift: 10배 정밀, 클릭하면 직접 입력, 0~1 값은 채움 막대).
  선택지는 목록에서, 색은 색 견본으로, 키는 칸을 누른 뒤 원하는 키를 눌러 지정하고, 대상은 레이어 목록에서 고릅니다.
* **웹사이트처럼 재배치** (기본값): 캔버스 폭을 바꾸거나 내보낸 사이트의 창 폭이 바뀌면 전체를 확대·축소하지 않고 배치를 바꿉니다.
  전체 폭 배경은 폭을 채우고, 내용은 원래 크기로 가운데에 있다가 좁아지면 여백 → 간격 → 상자 순으로 줄어듭니다.
  글자는 줄바꿈되고(28px보다 큰 제목만 작아짐), 들어가지 않는 열은 아래로 내려가며, 내용이 길어지면 세로가 늘어납니다.
  상자 안에 놓인 요소는 그 상자를 따라가고, 서로 겹친 장식은 한 덩어리로 축소됩니다.
  재배치한 뒤 손대지 않았다면 폭을 되돌렸을 때 원래 배치로 돌아옵니다. 배치를 고쳤거나 파일을 다시 열었다면 그 배치가 새 기준입니다.
* **캔버스 크기**: 아무것도 선택하지 않았을 때(또는 레이어만 선택했을 때) 속성창 맨 위 `캔버스 크기`에 가로·세로를 입력하거나,
  이동 도구로 캔버스 오른쪽·아래 가장자리와 모서리의 손잡이를 끌어 자유롭게 바꿉니다 (Shift: 10px 단위, `Ctrl+Z`로 되돌리기).
  내용은 `작업물 처리`에 따라 바뀝니다. 손잡이는 `그대로 두기`일 때만 내용을 고정하고, 나머지는 재배치합니다.
  웹 메뉴의 크기 프리셋은 재배치 / 비율 유지하며 맞추기 / 늘리기 / 그대로 두기 중에서 고르게 합니다.
* **사용자 스크립트 모듈**: 직접 쓴 자바스크립트를 매 프레임 또는 시작 시 실행합니다.
  ```js
  // api.self: 이 스프라이트 (x, y, rotation, scale, opacity, visible, fill, text, hovered)
  // api.find('이름'), api.all(), api.mouse {x, y, down, clicked}, api.key('Space'), api.scroll {y, progress}
  // api.time / api.dt / api.local, api.vars.get/set/add, api.emit('신호'), api.hasSignal('신호')
  // api.value / api.setValue(v) (모듈 스택 값), api.state (모듈별 저장 공간), api.open(url), api.random/lerp/clamp/log
  api.self.rotation = Math.atan2(api.mouse.y - api.self.y, api.mouse.x - api.self.x) * 180 / Math.PI;
  ```
  다른 사람이 만든 파일에 들어 있는 스크립트는 미리보기(실시간 미리보기, 웹 미리보기, 새 창에서 바로 실행)를 시작할 때 실행 여부를 묻습니다.
  내보낸 HTML/JS 파일에는 스크립트가 그대로 포함되어 실행되니, 신뢰하지 않는 파일은 내보내서 열지 마세요.
* **데스크톱 앱의 보안 제한**: 앱과 미리보기 창은 PC의 파일과 네트워크에 접근하지 못합니다 (폼 POST 전송, 원격 이미지·오디오는 내보낸 파일을 브라우저에서 열어 확인).
  이미지·글꼴은 가져오기로 문서에 넣으세요. 파일 경로로 적은 이미지는 표시되지 않습니다. 외부 링크는 주소를 확인한 뒤 열립니다.
* **저장**: `Ctrl+S`는 열었던(또는 한 번 저장한) 파일에 바로 저장, `Ctrl+Shift+S`는 다른 이름으로 저장. 저장하지 않은 변경이 있으면 열기·새 문서·닫기 전에 확인합니다.
  새 도큐먼트나 전체 템플릿으로 시작한 문서는 다른 파일을 덮어쓰지 않도록 첫 `Ctrl+S`에서 저장 위치를 묻습니다.
