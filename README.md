# [JSPen Studio] 포토샵형 네이티브 데스크톱 인터랙티브 스튜디오

> **오차 0.000% 하이브리드 네이티브 아키텍처 (Python + PyQt6)**  
> 윈도우 프레임리스 창, 커스텀 타이틀 바, 단축키, 네이티브 파일 저장 다이얼로그는 **100% C++/Qt 네이티브 소프트웨어**로 브라우저 느낌을 배제하였으며,  
> 중앙 캔버스는 **웹 Canvas 2D 엔진과 1:1 직결**되어 **"프로그램 화면에서 보는 그래픽/모션과 내보낸 자바스크립트 결과물 사이에 0.000% 오차 없는 완벽한 일치(WYSIWYG)"**를 보장합니다.

---

## 1. 빠른 시작 (원클릭 실행)

폴더 안에 있는 **`start.bat`** 파일을 더블 클릭하시면 콘솔창 없이 **포토샵 형태의 프레임리스 다크 테마 네이티브 데스크톱 프로그램 창**이 즉시 실행됩니다.

* 터미널 직접 실행:
  ```bash
  python main.py
  ```

* 단독 실행 파일(.exe) 생성:
  `build_exe.bat`을 실행하면 파이썬이 없는 PC에서도 바로 실행되는 `dist\JSPenStudio.exe`가 생성됩니다.

## 2. 주요 아키텍처 및 신규 기능

1. **프레임리스 윈도우 & 커스텀 타이틀 바 통합**:
   * OS 기본 투박한 타이틀 바를 제거하고, 앱의 메뉴바 줄을 직접 창 이동 드래그 및 최소화(`─`), 최대화(`□`), 닫기(`✕`)가 가능한 네이티브 타이틀 바로 통합.
2. **모듈 노드 모드 (Module Node Graph - Shift+Tab)**:
   * 상단 좌측 버튼 또는 `Shift+Tab`으로 전체 화면 비주얼 노드 편집기로 전환.
   * 스프라이트 노드, 모듈 노드, 모듈 합치기(Combine) 노드, 계산/설정(Math) 노드를 베지어 와이어로 연결.
   * **출력 노드(OUTPUT)에 연결된 모듈만 실제 런타임 및 내보내기에서 동작**합니다.
3. **포토샵형 레이어 & 스프라이트 계층 구조**:
   * 레이어(Layer)는 폴더/컨테이너 역할을 하며, 내부의 여러 스프라이트(도형, 곡선, 브러시, 텍스트)를 그룹 관리.
   * 레이어 접기/펼치기 및 드래그 앤 드롭으로 레이어 순서, 스프라이트 이동, 모듈 실행 순서 재배치 가능.
4. **타임라인 전체 드래그 기능 정상화 & 키프레임 다이아몬드 드래그**:
   * 렌더링 시 이벤트 리스너가 유실되지 않도록 완벽 보정.
   * 눈금자/그리드 스크러빙, 스플리터 높이 조절, 재생 헤드 드래그, 그리고 **캔버스 그리드 위의 키프레임 다이아몬드를 직접 마우스로 좌우 드래그하여 프레임 위치 이동** 가능.
5. **타임라인 키프레임의 모듈화 (Timeline Keyframe Module)**:
   * 타임라인에 찍은 키프레임이 모듈 단위(`timeline_keyframes`)로 캡슐화되어 노드 그래프에서 연결 및 제어 가능.
6. **실시간 모듈 미리보기 버튼 타임라인 이동 & `Ctrl+Space` 단축키**:
   * 미리보기 버튼이 타임라인 제어부로 이동하여 재생 컨트롤과 함께 관리되며, `Ctrl+Space`로 작업 도중 즉시 토글 가능.
7. **베지어 곡선 도구 (Bezier Curve Tool, C)**:
   * 3차 베지어 핸들(`cp1, cp2`)을 마우스로 실시간 조작하여 유려한 곡선 벡터 스프라이트 생성.
8. **브러시 도구 곡선 보정기 (Curve Stabilizer)**:
   * 옵션 바에서 `[곡선 보정 ON/OFF]` 토글 지원. 손떨림 없는 부드러운 스트로크 렌더링.
9. **창 팝업/플로팅 분리 기능 (Floating Panels, ⧉)**:
   * 속성 패널, 레이어 패널, 타임라인 헤더의 `⧉` 버튼을 누르면 패널이 화면 위에 독립적으로 띄워져 드래그 이동 및 크기 조절 가능.
10. **모듈 속성 인스펙터 & 작동 조건 설정**:
    * 레이어 목록이나 노드에서 모듈을 클릭하면 인스펙터에 모듈 세부 속성이 표시됨.
    * 사용자가 모든 파라미터를 수동 관리하며, 작동 조건(`상시`, `클릭 시`, `호버 시`, `키 입력 시`, `프레임 구간`)을 지정 가능.
11. **오픈소스 플러그인 시스템 & 환경 설정 (`Ctrl+,`)**:
    * 파일 메뉴 ➔ `환경 설정... (Ctrl+,)`에서 단축키 안내 및 오픈소스 플러그인 관리.
    * `window.JSPen.registerPlugin` API를 통해 누구나 자바스크립트 5줄로 커스텀 모듈 및 도구 추가 가능.
12. **스포이드 실시간 루페 스와치**:
    * 스포이드 도구(`I`) 사용 시 마우스 커서 옆에 실시간 색상 원형 돋보기와 16진수 색상 코드가 표시됨.
13. **플랫 2D 투명 체커보드 & 테두리 개선**:
    * 투명 배경의 입체감/그라데이션/그림자 셰이딩을 완전 제거하여 깔끔한 플랫 2D 격자로 변경.
    * 색상 선택 버튼의 흰색 테두리 제거 및 입력창 클릭 시 주황색 테두리 제거.
14. **돋보기 도구 조작 개선**:
    * 좌클릭: 확대, 우클릭: 축소, `Alt+클릭`: 100% 배율 초기화 및 아트보드 중앙 정렬.
15. **베벨(Chamfer)과 코너 라운딩(Radius)의 상호작용**:
    * 모따기된 베벨 모서리에 부드러운 곡률이 함께 조화되어 렌더링되며 수치가 상호 연동됨.

## 3. 포토샵 표준 1열 도구 모음 (Toolbox)

* ↖ `V` : **이동 도구 (Move Tool)** - 스프라이트 선택 및 8방향 자유 변형 박스
* ☩ `A` : **직접 선택 도구 (Direct Selection)** - 펜/곡선 앵커 포인트 및 핸들 개별 조작
* ⤹ `C` : **베지어 곡선 도구 (Bezier Curve Tool)** - 인터랙티브 핸들 벡터 곡선 드로잉
* ✒ `P` : **펜 도구 (Pen Tool)** - 다각 및 3차 베지어 벡터 드로잉
* ✎ `B` : **브러시 도구 (Brush Tool)** - 실시간 곡선 보정 기능 탑재
* ▭ `U` : **도형 도구 (Shape Tools)** - 사각형, 베벨 사각형, 타원/원
* T `T` : **문자 도구 (Type Tool)** - 텍스트 레이어 생성 및 타이포그래피 설정
* ⌖ `I` : **스포이드 도구 (Eyedropper)** - 실시간 커서 루페 색상 추출
* PAN `Space` : **손 도구 (Hand Tool)** - 뷰포트 자유 이동 (Pan)
* ⌕ `Z` : **돋보기 도구 (Zoom Tool)** - 클릭 확대, 우클릭 축소, Alt클릭 100% 초기화
* ◲ `D` / ⇄ `X` : 전경색/배경색 리셋 및 스왑
