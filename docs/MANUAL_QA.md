# 실기기 수동 점검 체크리스트

자동 테스트(`npm test`, `python tests/desktop_smoke.py`)는 헤드리스 Chromium과 오프스크린 Qt에서 실행됩니다.
아래 항목은 실제 화면·장치가 필요해서 자동화하지 못한 부분입니다. 릴리스 전에 Windows PC에서 확인하세요.

## 1. 데스크톱 앱 (Windows, `start.bat` 또는 `dist\JSPenStudio.exe`)
- [ ] 콘솔 창 없이 프레임리스 창이 열린다.
- [ ] 메뉴바 빈 곳을 드래그하면 창이 이동하고, 화면 가장자리로 끌면 Windows 스냅이 동작한다.
- [ ] 최소화 / 최대화(두 번 누르면 복원) / 닫기 버튼이 동작한다.
- [ ] `Ctrl+S`: 저장 대화상자가 열리고, 같은 파일을 다시 저장하면 이전 경로가 기본값으로 나온다.
- [ ] `Ctrl+O`: 열기 대화상자에서 `.jspen` 파일을 열 수 있다. 손상된 파일은 오류 알림만 뜨고 기존 문서가 유지된다.
- [ ] 탐색기에서 `.jspen` 파일을 더블클릭하면 앱이 그 파일을 연 채로 실행된다 (파일 연결).
- [ ] `.jspen` 파일을 창으로 끌어다 놓으면 열린다.
- [ ] 내보내기 창의 "파일 다운로드", 웹 메뉴의 웹사이트 내보내기에서 저장 대화상자가 뜨고 파일이 저장된다.
- [ ] 템플릿 갤러리에 템플릿 7개가 보이고 삽입된다 (exe 빌드에서도).
- [ ] GPU 가속: 복잡한 템플릿(full_landing)에서 확대/이동과 `Ctrl+Space` 미리보기가 부드럽다. 문제가 있으면
      환경 변수 `QTWEBENGINE_CHROMIUM_FLAGS=--disable-gpu`로 실행해 비교한다.
- [ ] 고해상도 모니터(125%/150% 배율)에서 글자와 아이콘이 흐리지 않다.

## 2. 오디오 (스튜디오 `Ctrl+Space` 미리보기와 내보낸 페이지 모두)
- [ ] `내장 신디사이저 SFX`: 클릭 / 마우스 진입 / 트리거 / 신호 시점마다 소리가 한 번씩 난다 (6가지 소리).
- [ ] `오디오 파일 재생`: mp3 URL과 프로젝트 폴더의 상대 경로 파일이 재생된다. 반복 옵션이 동작한다.
- [ ] `소리 반응 (문서 효과음)`: 효과음이 날 때 연결한 속성이 커진다.
- [ ] `소리 반응 (마이크)`: 데스크톱 앱에서 권한 확인 창이 뜨고, "아니요"를 누르면 마이크가 켜지지 않는다.
      "예"를 누르면 말할 때 크기가 반응한다. 브라우저(내보낸 페이지)에서는 브라우저의 권한 요청이 뜬다.

## 3. 브라우저
- [ ] Chrome / Edge / Firefox / Safari에서 내보낸 JS·웹사이트 페이지의 인터랙션(드래그, 호버, 스크롤 등장, 섹션 이동)이 동작한다.
- [ ] 모바일(터치)에서 드래그와 버튼 터치가 동작하고, 페이지 스크롤이 막히지 않는다.
- [ ] 한글 이름의 문서를 브라우저 모드에서 `Ctrl+S`로 저장하면 파일명이 한글로 저장된다.
- [ ] 화면 낭독기(NVDA / VoiceOver)로 내보낸 JS 페이지의 텍스트와 링크를 읽을 수 있다.
